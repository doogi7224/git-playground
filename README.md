# Gearwood: The Broken Spring (기어우드: 파괴된 태엽)

React Native(Expo)로 만든 사이드스크롤 액션 플랫포머입니다. 숲 탐험가가 점프·대시·루트훅 그래플·스톰프를 연결하며 밝은 고대 숲을 질주합니다. 현재 게임 규칙과 협업 상태는 [CLAUDE.md](./CLAUDE.md), [AI_COLLAB.md](./AI_COLLAB.md)를 참고하세요. `docs/gearwood-*.md`는 초기 기획 아카이브입니다.

## 실행 방법

```bash
npm install
npm run start   # Expo 개발 서버 실행 (QR코드로 Expo Go에서 실행)
npm run android # 안드로이드 에뮬레이터/기기
npm run ios     # iOS 시뮬레이터 (macOS 필요)
npm run web     # 웹 브라우저에서 실행
```

## 조작법

- ◀ / ▶: 좌우 이동
- ▲: 점프
- »: 대시 — 짧은 무적 프레임과 함께 순간 돌진 (공중 1회, 착지 시 재충전 / 지상은 쿨다운만 있으면 재사용 가능)
- ◎: 루트훅 — 근처 루트 포인트에서 버튼을 누르고 있으면 그래플 스윙, 떼면 그 순간의 관성이 그대로 이동에 이어짐
- 적을 위에서 밟으면 처치, 옆에서 부딪히면 목숨 감소 (일부 몬스터는 상태에 따라 처치법이 다름 — 몬스터 디자인 문서 참고)
- 스톰프·대시를 끊김 없이 연계하면 오버드라이브 게이지가 차오르고, 가득 차면 8초간 이동속도·점프력 상승 + 코인 2배
- 죽으면 레벨 시작이 아니라 가장 최근에 지난 체크포인트에서 부활
- 코인을 모으고 깃발에 도착하면 클리어

## 게임 콘텐츠

- **블룸 시프트**: 레벨 곳곳의 시프트 노드를 밟으면 주변 지형이 기계↔자연 상태로 전환되며, 상태별로만 존재하는 발판·기믹이 나타남 (4개 구간)
- **몬스터 5종**: 코그마이트, 스포어 스프라이트(대시로만 처치), 프레셔 피스톤(블룸 시프트로만 무력화), 바이오 코일, 스팀 블로어(미니보스) — 상세는 [몬스터 디자인 문서](./docs/gearwood-monster-design.md)
- 2개 구역, 총 4700px 길이의 단일 스테이지, 체크포인트 5개

## 알려진 한계

- 기어 소켓(모듈형 코그 장착) 시스템은 미구현 — 스테이지 클리어 후 재배치하는 인벤토리 UI가 필요해 현재의 단일 연속 레벨 구조와는 별도 설계가 필요합니다.
- 오버드라이브는 스톰프·대시 연계만 반영 (기획서의 벽점프·그라인드는 게임에 없음)
- 실기기(Expo Go) 테스트는 아직 진행하지 않았고, Expo 웹 빌드 + Playwright로만 검증했습니다.

## 프로젝트 구조

```
src/
  game/
    constants.ts   # 물리/게임 상수
    types.ts       # 타입 정의
    level.ts       # 레벨(지형, 적, 코인, 깃발, 시프트 노드, 체크포인트 등) 데이터
    physics.ts     # 게임 루프 업데이트 로직 (이동/충돌/각 몬스터·기믹 처리)
  components/      # 플레이어, 몬스터 5종, 발판, 깃발, 시프트 노드, 루트 포인트,
                   # 체크포인트, 조작 버튼, HUD 렌더링
  screens/
    StartScreen.tsx # 시작 화면
    GameScreen.tsx  # 실제 게임 화면 (게임 루프 실행)
App.tsx             # 화면 전환
```
