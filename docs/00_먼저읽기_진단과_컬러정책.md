## 1. 무엇이 문제였나

레퍼런스는 **탕탕특공대(Survivor.io)** 계열 — 어두운 차가운 바닥 + 고채도 캐릭터 + 네온 이펙트.

| 항목 | 상태 | 판정 |
|---|---|---|
| 그록 원본 스프라이트 24종 | 색·선·디테일 양호 | **A-. 재생성 불필요** |
| 팔레트 강제 스냅 파이프라인 | 원본 고유색을 전부 갈색으로 파괴 | **F. 정책 폐기** |
| 바닥 | M0 격자선. 맵 바꿔도 안 변함 | **F** |
| 이펙트·픽업 | 단색 하드엣지 도형 | **F** |
| 레벨업 UI | 기본 테마 버튼, 가로 배치 | **D** |
| MultiMesh 아틀라스 구조 | 드로우콜 1개 | **A. 유지** |

구체적 증상:
- `blizzard` 푸른 소용돌이 → 갈회색
- `discharge_delay` 빨간 밀랍 인장 → 갈색 (개그 소멸)
- `weed` 초록 → 카키 / `night_watch` 푸른 야간톤 → 카키
- 플레이어 얼굴 살색 → 초록, 손 → 순백 덩어리, 전투화 검정 → 올리브
- 혹한기 맵 바닥이 연병장과 동일한 국방색
- `recruit` 적이 플레이어와 같은 올리브 군복 → 플레이어 위치 식별 불가

## 2. 기획서 정정 — 아래 두 항목 폐기

| 폐기 | 원문 | 문제 |
|---|---|---|
| 기획서 3.2 | "배경/지형 채도 40% 이하로 눌러버림", 전 화면 국방색 | 캐릭터도 국방색이라 안 뜸 |
| 기획서 4.3-2 | "팔레트 강제 스냅 — 스타일 통일의 핵심" | 원본 24장 고유색 파괴 |

**대체 원칙:**

> **바닥은 어둡고 차갑게, 캐릭터는 밝고 따뜻하게, 이펙트는 네온으로 태운다.**
>
> 색 분리를 *채도를 눌러서*가 아니라 **색온도와 명도를 갈라서** 만든다.

군대라는 주제(올리브 군복)는 **캐릭터 쪽에 남기고**, 바닥을 어둡게 내려 대비를 얻습니다. 컨셉은 유지되고 가독성만 올라갑니다.

## 3. 새 컬러 시스템

### 3-1. 바닥 (맵별 · 차갑고 어둡게 · 명도 0.20 이하)

```
parade_ground    기본 #1E2A22  디테일 #2A3A2C  음영 #141C16   짙은 녹흑
obstacle_course  기본 #262014  디테일 #3A3222  음영 #17130C   짙은 흙
winter_field     기본 #1C2836  디테일 #2C3C4E  음영 #121A24   짙은 청
night_gate       기본 #141C2A  디테일 #1E2A3C  음영 #0C1018   야간
```

### 3-2. 캐릭터 (스냅 금지 · 보정만)

```
채도       × 1.15
명도       0.30 ~ 0.92 로 클램프
살색 보호  HSV hue 20~45°, sat 0.15~0.60 구간은 보정 제외
외곽선     명도 0.15 이하 → 잉크 #14180F 로 통일
```

**예약 색상 회피는 스냅이 아니라 hue 이동으로:**

```
시아 172~196° & sat>0.5              → 200° 쪽으로 12° 밀기
금색 38~52°  & sat>0.6 & val>0.7     → 30°  쪽으로 12° 밀기
진홍 348~8°  & sat>0.65              → 20°  쪽으로 12° 밀기
```
→ 눈보라 푸른색, 잡초 초록, 서류 빨간 인장이 살아남으면서 FX 색과는 안 겹칩니다.

### 3-3. FX (HDR — 네온의 핵심)

```
플레이어 공격  #3FE0D0 × 2.5
크리티컬       #FFC94A × 3.0
적 위험/장판   #FF1F3D × 2.0
회복           #8FE388 × 2.0
경험치 픽업    #7FE0FF × 1.8
```
`× n` = 셰이더에서 `COLOR.rgb *= n`. **1.0을 넘겨야 글로우가 터집니다.**
