# M4 메타 진행 — 저장 · PX 상점 · 해금 · 표창장

한 판이 끝나면 남는 것을 만드는 단계다. 20분을 버티든 3분에 쓰러지든 **월급**이 나오고,
그 월급으로 PX에서 영구 강화를 사고, 누적 기록이 캐릭터와 맵을 연다.

## 한 눈에

```
한 판 종료
  └─ GameState.end_run(victory)
       └─ SaveSystem.record_run(victory, run_stats)
            ├─ 월급 산출        data/progression.tres 의 공식
            ├─ 누적 통계 갱신    total_kills / runs_won / best_level ...
            ├─ 표창장 판정       data/commendations/*.tres
            ├─ 무료 해금 판정    data/unlocks/*.tres (price = 0)
            └─ 저장             user://savegame.cfg
```

**정산은 `GameState.end_run` 한 곳에서만 한다.** 결과 화면은 돌려받은 딕셔너리를 읽어서
찍기만 한다 — 화면에서 `record_run` 을 또 부르면 월급이 두 번 들어간다.

## 월급 공식

`ProgressionData.salary_for()`. 값은 전부 `data/progression.tres` 다.

| 항목 | 기본값 |
|---|---|
| 처치 1마리당 | 0.06 |
| 진급 1레벨당 | 4 |
| 생존 1분당 | 12 |
| 보스 1마리당 | 150 |
| 전역 성공 보너스 | 500 |

10원 단위로 반올림한다. 군대 월급에 1원 단위는 안 어울린다.

## PX 상점 10종 (`data/px/`)

| id | 이름 | 스탯 | 방식 | 레벨당 | 최대 | 시작가 |
|---|---|---|---|---|---|---|
| px_ration | 건빵 추가 배급 | max_hp | ADD | +8 | 5 | 120 |
| px_boots | 신형 전투화 | speed_mult | MULT | +4% | 5 | 150 |
| px_whetstone | 숫돌 | damage_mult | MULT | +5% | 5 | 200 |
| px_stopwatch | 초시계 | cooldown_mult | MULT | −3% | 5 | 220 |
| px_insole | 자석 깔창 | magnet_mult | MULT | +12% | 3 | 130 |
| px_vest | 방탄복 | armor | ADD | +1 | 5 | 180 |
| px_diary | 수양록 | xp_mult | MULT | +5% | 4 | 200 |
| px_charm | 행운의 부적 | luck | ADD | +0.04 | 3 | 260 |
| px_coffee | 커피믹스 | regen | ADD | +0.3/s | 3 | 240 |
| px_chaltteok | 찰떡파이 비축 | revives | ADD | +1 | 1 | 1200 |

가격은 `base_cost × growth^현재레벨`. **`stat` 은 `Player` 의 필드 이름 그대로**이고,
`Player._apply_px_upgrades()` 가 캐릭터 기본값 위에 한 번만 얹는다.
순서는 **PX 가 먼저, 런 중 명령서가 나중**이다.

새 항목을 넣으려면 `.tres` 하나 만들고 `data/px/px_shop.tres` 배열에 넣으면 끝이다.
GDScript 는 안 건드린다.

## 해금 (`data/unlocks/`)

두 갈래다.

- **조건형** (`price = 0`) — 누적 통계가 조건을 넘으면 결산 때 저절로 열린다.
- **구매형** (`price > 0`) — 조건을 넘긴 **뒤에** 월급을 내야 열린다.

캐릭터 8 + 맵 3 = 11건 전부 해금표에 있다. **출두 신고 화면은 이 표를 그대로 그린다** —
표에 없는 캐릭터는 화면에 안 뜬다. 목록이 두 군데로 갈라지지 않게 일부러 그렇게 뒀고,
`tests/run_tests.gd` 가 `data/characters/*` 전부에 해금 항목이 있는지 검사한다.

`target_id` 는 **파일 이름과 같아야 한다** (`park_sergeant` → `data/characters/park_sergeant.tres`).
아레나가 저장된 선택을 이 규약으로 불러오기 때문이다. 테스트가 이것도 검사한다.

## 표창장 12장 (`data/commendations/`)

조건을 채우면 자동 발급 + 일시금. 조건은 `MetaCondition` 한 줄(종류 + 임계값)이라
새 표창장은 `.tres` 하나면 된다.

보상 월급이 다시 다른 표창장의 조건(`TOTAL_SALARY`)을 채우는 **연쇄**가 있어서,
`check_commendations()` 는 더 나올 게 없을 때까지 최대 8번 돈다.

## 저장 형식

`user://savegame.cfg` — `ConfigFile`, `[save]` 섹션 하나에 키 하나씩.

**임시 파일에 먼저 쓰고 옮긴다.** 저장 중에 꺼져도 기존 세이브가 남는다.

### 딕셔너리 키는 전부 String 이다

Godot 4 의 `Dictionary` 는 `&"a"` 와 `"a"` 를 **다른 키로 본다.** 저장 파일을 한 번
왕복하면 `StringName` 키가 `String` 으로 바뀌기 때문에, 섞어 쓰면 누적 통계가 조용히
0으로 리셋된다. `MetaCondition.STAT_KEYS` 가 `Array[String]` 인 이유다.

### 버전 마이그레이션

`SAVE_VERSION` 이 현재 2다. `_migrate()` 에 버전마다 한 칸씩 쌓는다.
v1 → v2 는 없던 누적 통계를 채운다(해금은 그대로 둔다).

그 뒤에 `_ensure_shape()` 가 타입까지 확인한다. 손으로 고친 세이브나 옛 형식이 들어와도
게임이 죽지 않고, 기본 캐릭터(김이병)와 기본 맵(연병장)은 **절대 잠기지 않는다.**

## 화면 (`ui/meta/`)

`meta_root.tscn` 이 main_scene 이다. 자식 넷을 켜고 끈다 — 씬을 갈아끼우면 매번 다시
지으면서 스크롤 위치와 포커스가 날아간다.

| 화면 | 파일 | 내용 |
|---|---|---|
| 메인 메뉴 | `main_menu.gd` | 출두 / PX / 표창장 / 설정 / 퇴소 + 보유 월급 |
| 출두 신고 | `character_select.gd` | 캐릭터·맵 선택, 잠긴 것은 조건/가격 |
| PX 상점 | `px_shop.gd` | 10종, 레벨 눈금 ■■■□□, 구매 |
| 표창장 | `commendation_board.gd` | 12장, 받은 것은 빨간 인장, 아직은 진행률 |

겉모습은 `meta_ui.gd` 한 곳에 모아 뒀다 — 갱지 `#E4DCC4`, 타자기 검정 `#2B2A26`,
인장 진홍 `#C8102E`, 강조 금색 `#FFC94A`.

화면은 `.tscn` 이 아니라 코드로 짓는다. 항목이 `.tres` 에서 오기 때문에 어차피 런타임에
만들어야 하고, 씬 파일로 두면 목록이 두 군데로 갈라진다.
(규칙 3 "런타임 instantiate 금지" 는 전장의 적·투사체 이야기다. 메뉴는 게임 루프 밖이다.)

## 아레나가 선택을 읽는 법

메뉴에서 고른 값은 `SaveSystem` 에 저장되고, `arena.gd._apply_saved_selection()` 이
`data/characters/<id>.tres` 를 직접 읽어서 씬에 박힌 기본값을 덮는다.
씬 전환 사이에 값을 들고 있을 자리가 없어서 저장이 그 자리를 대신한다.

씬에 박힌 값은 도구용 폴백으로 남는다 — `tools/screenshot.sh` 처럼 아레나를 직접 여는
경우에도 기본값과 저장된 선택이 같아서 결과가 달라지지 않는다.

## 검증

```bash
tools/test.sh                  # 저장 왕복 · 마이그레이션 · PX · 해금 · 표창장 · 결산 · 화면 배선
tools/menu_shot.sh --out-dir=/tmp/menu --salary=99999 --fake-progress
```

`tools/menu_shot.sh` 는 메타 화면 4종을 실제 렌더러로 찍는다. 헤드리스 단위 테스트는
"글자가 겹쳐서 안 읽힌다" 를 절대 못 잡는다. 화면이 거의 비어 있으면 종료 코드 1.

**테스트는 진짜 세이브를 건드리지 않는다.** `_sandbox_save_system()` 이 `_run_all` 맨 앞에서
저장 경로를 `user://test_savegame.cfg` 로 돌리고 autosave 를 끈다. 아레나 스모크 테스트도
한 판을 끝내면서 결산을 부르기 때문에, 이게 없으면 테스트를 돌릴 때마다 월급이 올라간다.
