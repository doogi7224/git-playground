# 그래픽 폴리시 (기획서 프롬프트 6)

기획서 3.3의 "인디 티 벗기는 핵심"을 구현한 부분. 전부 설정에서 개별로 끌 수 있다.

## 히트 필 3종

| 연출 | 파일 | 어떻게 |
|---|---|---|
| 흰 플래시 | `vfx/shaders/hit_flash.gdshader` + `vfx/hit_flash.gd` | 개별 스프라이트용. 적 무리는 `blob_multimesh` 가 `INSTANCE_CUSTOM` 으로 처리 |
| 히트스톱 | `core/combat/hit_stop.gd` | 크리티컬·보스 사망 시 `time_scale` 0.05 → 0.04초 후 복구 |
| 스쿼시&스트레치 | `vfx/shaders/squash_stretch.gdshader` | 정점 셰이더. 스케일 애니가 아니다 |

### 히트 플래시는 시간이 아니라 **프레임**으로 센다
히트스톱으로 `time_scale` 이 0.05가 된 상태에서 "0.03초 뒤 끄기"를 게임 시간으로 재면
실제로는 0.6초가 걸린다. 강타할 때마다 캐릭터가 하얗게 굳는다. 그래서 프레임 수로 센다.

### 히트스톱 복귀는 **실시간**으로 잰다
같은 이유가 반대로 적용된다. `_process` 의 delta 는 `time_scale` 이 곱해진 값이라,
0.04초를 그걸로 세면 0.8초가 된다. `Time.get_ticks_usec()` 을 쓴다.
크리티컬이 연달아 터져도 게임이 계속 느려지지 않게 최소 간격(0.22초)도 둔다.

## 데미지 넘버 — 개별 Label 금지

`vfx/damage_numbers.gd`. 기획서 6.2의 요구사항 그대로.

- 숫자 0~9 를 **SubViewport 로 한 번 구워서** 폰트 아틀라스를 만든다(흰 글자 + 어두운 외곽선)
- **글리프 하나가 MultiMesh 인스턴스 하나.** 120개 숫자 × 최대 6자리 = 인스턴스 720개, 드로우콜 1
- 동시 **120개 캡**. 넘치면 가장 오래된 것부터 밀어낸다
- 크리티컬은 **크기 1.5배 + 금색** (`#FFC94A` — 기획서 3.2의 플레이어 독점색)
- 설정에서 끄면 `EnemyManager` 가 시그널 자체를 쏘지 않는다(3,000마리면 초당 수천 번이다)

### 걸렸던 함정: QuadMesh 를 2D에서 쓰면 세로가 뒤집힌다
`QuadMesh` 는 3D 기준(+Y 위)으로 UV를 만드는데 2D는 +Y가 아래다. 그래서 텍스처의 V가 반대가 된다.
적/픽업을 그리는 `blob` 셰이더는 상하 대칭인 원이라 아무도 몰랐는데, 글자를 그리자마자
**"1"과 "4"가 거꾸로** 찍혔다("3"은 상하가 비슷해서 멀쩡해 보여서 더 헷갈렸다).
`vec2(UV.x, 1.0 - UV.y)` 로 뒤집어서 해결했다. MultiMesh 로 텍스처를 그릴 일이 또 생기면 같은 걸 조심할 것.

## 포스트프로세싱

- `data/gfx_environment.tres` — `WorldEnvironment` 글로우 0.6, 대비 +10%, 채도 +5%
- `vfx/shaders/post_process.gdshader` — 비네트 + 아주 약한 색수차. 기획서가 "강하면 촌스러움"이라
  못 박아서 약하게 잡았다. 실측으로 화면 코너가 중앙보다 **8% 어둡다** — 있는 줄도 모르게 있는 정도가 맞다.
- 색수차는 화면 가장자리에서만 적용된다(가운데까지 번지면 눈이 아프다)

## 2D 라이팅

- `CanvasModulate` — 맵별 전역 톤. `MapData.ambient_tint` 에서 온다.
  연병장은 `(0.90, 0.92, 0.86)`, 야간 위병소는 M3에서 짙은 남색이 된다.
- `PointLight2D` — 플레이어 발밑 림라이트(`vfx/light_radial.tres`).
  총구 화염·조명탄·연막 발광은 M2에서 실아트와 같이 붙인다.

## 화면 흔들림 = 접근성 문제

`vfx/screen_shake.gd`. 랜덤 오프셋(화이트 노이즈)으로 흔들면 그냥 지직거린다.
`FastNoiseLite` 의 Perlin 을 시간축으로 훑어서 프레임 간 이동이 이어지게 한다.
흔들림 양은 trauma의 **제곱**에 비례한다 — 약한 타격은 거의 안 흔들리고 강타만 크게 흔든다.

`Settings.screen_shake = 0` 이면 완전히 멈춘다. 옵션 슬라이더로 조절한다(기획서 3.3).

## 설정

`autoload/settings.gd` (6번째 오토로드). Esc → `ui/options_panel.tscn`.

글로우 / 비네트 / 색수차 / 데미지 넘버 / 히트스톱 / 2D 라이팅 개별 토글 + 흔들림 강도 슬라이더
+ **저사양 프리셋**(글로우·색수차·데미지 넘버·라이팅 끄고 파티클 밀도 35%).
값은 `SaveSystem.data["settings"]` 에 들어간다.

제대로 된 옵션 화면은 M5. 지금은 켜고 끄는 게 확인되는 최소한만 있다.

## 성능

데미지 넘버와 포스트프로세싱을 얹은 뒤에도 3,000마리 물리 1틱 **7.3ms(예산의 44%)**.
데미지 넘버는 드로우콜 1개를 더 쓴다.
