# GEARWOOD (기어우드)

**Game Design Document · Refinement v0.2**

기어우드 — 톱니와 뿌리가 뒤엉킨 숲, 스프라우트의 태엽 모험

## 01 — 콘셉트 및 아트 방향성

**한 줄 세계관.** 수백 년 전 대륙 전체를 움직이던 시계공학 문명이 멸망하고, 멈춰버린 거대한 태엽 유적 위로 숲이 자라나 기계와 생명이 하나의 생태계처럼 뒤엉킨 땅 — **기어숲(Gearwood)**.

정지해 있던 대륙 중심부의 **그레이트 스프링**이 최근 다시 돌기 시작하며 폭주 징후를 보이자, 숲을 관리하던 자동인형 지성체 **큐레이터**는 이를 '오류'로 규정하고 숲 전체를 순수 기계 상태로 되돌리려 한다. 씨앗과 부속품이 뒤섞인 흙에서 태어난 반(半)기계 정령 **스프라우트**만이 두 세계의 언어를 동시에 이해하는 유일한 존재다.

마리오식 '납치된 공주 구출'의 단순 목표 대신, 갈등 구도를 **'방치된 다양성 vs 강제된 효율'**로 설정한다. 큐레이터도 완전한 악역이 아니라 원래 숲을 지키려던 목적이 왜곡된 존재로 그려 후반 서사에 반전 여지를 남기고, 엔딩을 **'스프링을 완전히 멈출 것인가, 재가동해 숲의 형태를 되돌릴 수 없이 바꿀 것인가'**로 분기시켜 재플레이 동기를 서사 층위에서도 확보한다.

### 세계관 요약

| 항목 | 내용 |
|---|---|
| 무대 | 기어숲(Gearwood) — 멈춘 태엽 문명 유적 위에 자란 기계×자연 융합 생태계 |
| 주인공 | 스프라우트 — 씨앗과 부속품에서 태어난 반기계 정령, 3개의 기어 소켓 보유 |
| 대립축 | 큐레이터(자동인형 지성체) — "숲은 오류다, 순수 기계로 재정렬한다" |
| 핵심 갈등 | 선악 대립이 아닌 '방치된 다양성 vs 강제된 효율'의 가치관 충돌 |
| 타겟층 | 10–35세, 캐주얼 액션 경험자 + 셀레스트·할로우나이트류 코어 플랫포머 팬 크로스오버 |

### 비주얼 스타일 — 페인터리 픽셀아트

- 베이스 32px 그리드 캐릭터 스프라이트 + 동적 라이팅·파티클로 유화 질감의 명암을 얹는 방식 (참고: Dead Cells, Owlboy의 마감 방식 — 팔레트는 독자 구성).
- 배경은 4레이어 시차 디오라마: 최원경(안개 낀 태엽탑 실루엣) → 원경(거대 기어 골조) → 중경(플레이 지형) → 근경(넝쿨·증기 파티클 오버레이).
- **색채로 지형 상태를 표시하는 UX 규칙**: 기계 구역은 황동·구리 톤, 자연 구역은 이끼·에메랄드 톤 고정 배색. 플레이어가 색만 보고도 현재 지형이 '기계'인지 '자연'인지 즉시 인지하도록 설계 — 2장의 블룸 시프트 메커닉과 직결.

## 02 — 메인 게임플레이 메카닉 & 조작성

**조작 목표 감각**: "가속은 즉각적으로, 감속은 관성 있게, 실수는 관대하게." 마리오 특유의 직관적인 즉시 반응성은 유지하되, 관성 구간을 살짝 늘려 셀레스트급 정밀 컨트롤을 원하는 유저에게도 조작 깊이를 제공한다.

### 기본 조작 수치

| 항목 | 수치 | 비고 |
|---|---|---|
| 지상 최고속도 도달 | 0.12초 | 입력 즉시 반응하는 아케이드 감각 |
| 정지 시 감속 | 0.22초 | 살짝 미끄러지는 관성감 부여 |
| 점프 최고높이 조절 | 홀드 0.1–0.35초 | 버튼 유지 시간에 비례한 가변 점프 |
| 코요테 타임 | 4f (≈0.066초) | 발판 이탈 직후 점프 유예 |
| 점프 버퍼 | 6f (≈0.1초) | 착지 직전 선입력 허용 |
| 공중 대시 | 1회 / 공중 | 지상·벽 접촉 시 재충전, 0.15초 무적 프레임 부여 |
| 벽 슬라이드 낙하속도 | 최고 낙하의 45% | 벽점프 판단 시간 확보 |
| 공중 제어력 (Air Control) | 지상의 85% | 공중에서도 정밀한 방향 전환을 허용해 미세 컨트롤 보장 |
| 최고 낙하 속도 (Terminal Velocity) | 18.5 m/s (1200 px/s) | 낙하 가속 무한 증가로 인한 조작 불능 방지 |
| 중력 가속도 (Gravity Scale) | 상승 1.0x / 정점 0.7x / 낙하 1.4x | 점프 정점에서 체류감을 주고, 낙하는 묵직하고 빠르게 |

대시의 **무적 프레임**은 단순 이동기가 아니라 '위험 지형·투사체 회피 겸 통과'라는 이중 용도로 설계한다. 이 규칙은 5장의 몬스터·보스 공략에도 그대로 재사용되어, 플레이어가 한 번 배운 규칙을 게임 전체에서 일관되게 적용할 수 있게 한다.

### 핵심 특수 능력 — 기어 소켓(Gear Socket) 시스템

마리오의 버섯·꽃처럼 캐릭터 전체를 단일 상태로 바꾸는 파워업 대신, 머리·몸통·발 3개 소켓에 **코그(Cog)**를 장착하는 모듈형 빌드 시스템을 채택한다. 코그는 스테이지에서 습득하며 클리어 후 자유롭게 재배치할 수 있어, *같은 스테이지를 다른 조합으로 재도전*하는 재플레이 동기가 시스템 자체에 내장된다.

| 코그 | 슬롯 | 효과 |
|---|---|---|
| 스프링 코그 | 발 | 점프 최고높이 +18%, 벽점프 수평거리 +25% |
| 마그넷 코그 | 몸통 | 반경 내 코인·기어 파츠 자동 흡수, 금속 지형에 짧게 흡착 이동 |
| 포토신 코그 | 머리 | 3초 이상 정지 시 광합성 차지 완료, 차지 상태로 대시하면 '과성장 블록' 파괴 |
| 스팀부스트 코그 | 발 | 대시 직후 0.2초 추가 관성 부스트. 대신 착지 경직이 소폭 증가 |
| 루트훅 코그 | 몸통 | 그래플 포인트 사거리 +30%, 스윙 도중 추가 점프 1회 허용 |
| 미러 코그 | 머리 | 최근 4초 이동 경로를 잔상으로 기록, 사망 시 그 지점에서 즉시 재시도 |

### 기어 소켓 조합 시너지 시스템

단순 모듈 장착을 넘어, 특정 소켓 조합 시 발동하는 **조합 패시브(Synergy Passives)**를 두어 빌드 연구의 깊이를 더한다.

| 시너지 명칭 | 필요 조합 (머리 / 몸통 / 발) | 시너지 효과 |
|---|---|---|
| 캐논 점프 | 자유 / 루트훅 코그 / 스프링 코그 | 루트훅 스윙 정점 릴리즈 시 점프 최고높이·수평 관성에 **+30%** 추가 보너스 |
| 오버차지 임팩트 | 포토신 코그 / 마그넷 코그 / 자유 | 과성장 블록 파괴 시 주변 자원 즉시 전체 흡수 + 1.5초간 대시 무적 지속 |
| 스팀 가디언 | 미러 코그 / 자유 / 스팀부스트 코그 | 대시 부스트 중 피격 시 1회 데미지 무효화 + 잔상 지점으로 즉시 텔레포트 |

### 시그니처 능력 3종

- **루트훅(Root-Hook)** — 진자 스윙 물리 기반 그래플. 자유 그래플이 아니라 지정된 '루트 포인트'에만 반응해, 레벨 디자이너가 동선을 명확히 통제할 수 있다. 스윙 정점에서 릴리즈하면 관성이 그대로 점프에 가산된다.
- **블룸 시프트(Bloom Shift)** — 필드의 '시프트 노드'를 기점으로 주변 지형을 기계형↔자연형으로 실시간 전환. 같은 좌표, 다른 성질의 발판(회전 톱니 ↔ 휘어지는 덩굴)이 배치되어 이동 리듬 자체가 바뀐다.
- **오버드라이브 게이지** — 벽점프·대시·스톰프·그라인드를 끊김 없이 연계할수록 상승하는 콤보 게이지. 가득 차면 8초간 이동속도·점프력 15% 상승과 코인 2배 획득이 발동되는, 이동 숙련도를 명시적 자원으로 환산하는 '흐름 보상' 레이어.

## 03 — 슈퍼마리오와의 차별점

| 구분 | 슈퍼마리오 | 기어우드 | 플레이어 경험 차이 |
|---|---|---|---|
| 지형 상태 | 고정된 단일 레이어 | 블룸 시프트로 기계↔자연 실시간 전환 | 암기형 플랫포밍 → 상태 판단형 퍼즐 플랫포밍 |
| 능력 습득 | 버섯·꽃 등 선형적 단일 파워업 | 3슬롯 코그 모듈 조합 | '더 세짐' → '다르게 풀기'로 성장 개념 전환 |
| 이동 보상 | 코인·점수가 수집 그 자체가 목적 | 오버드라이브로 이동 흐름이 직접 자원화 | 클리어 목표형 → 플레이 스타일 표현형 |

### 3대 차별화 포인트

1. **환경전환 (Bloom Shift)** — 정적 지형이 아니라 플레이어 조작으로 실시간 전환되는 이중 상태 지형. 퍼즐성과 플랫포밍을 결합한다.
2. **모듈형 빌드 (기어 소켓)** — 단일 변신이 아닌 조합형 능력치. 재도전마다 다른 전략과 경로가 가능해진다.
3. **모멘텀 경제 (오버드라이브)** — 이동 자체의 숙련도를 명시적 자원·점수로 환산해 스피드런과 랭킹 재플레이를 유도한다.

### 블룸 시프트 트리거 메카닉 구체화

블룸 시프트의 작동 방식을 **노드 타격형**과 **오버드라이브 발동형** 2가지 모드로 분리해, 레벨 퍼즐과 피지컬 액션의 균형을 잡는다.

1. **필드 노드 타격 (기본 모드)** — 레벨에 배치된 '시프트 노드'를 근접 공격 / 스톰프 / 루트훅으로 타격하면 주변 반경 12타일 지형이 실시간 전환된다. 레벨 디자이너가 의도한 정교한 플랫포밍 퍼즐 구간의 핵심 요소.
2. **오버드라이브 시프트 (고급 모드)** — 오버드라이브 게이지가 50% 이상일 때 `대시 + 스톰프` 동시 입력 시, 플레이어 위치를 기점으로 3초간 임시 블룸 시프트 영역이 생성된다. 숙련자의 스피드런·지름길 개척 전용 기능.

### 참신한 기믹 제안 (개발 우선순위 순)

1. **정역학 기믹 — 균형 기어 리프트.** 양쪽에 무게추가 걸리는 시소형 톱니 리프트. 플레이어 위치뿐 아니라 소지 중인 코그 파츠·씨앗 폭탄의 무게까지 실시간 반영해 기울기가 계산되는 간단한 정역학 퍼즐.
2. **상호작용 기믹 — 메아리 씨앗.** 벽에 심으면 일정 시간 뒤 발판으로 자라나는 오브젝트. 미리 심어두고 우회 경로로 돌아와 완성된 발판을 이용하는 '시간차 레벨 디자인'.
3. **타임 요소 — 주간 태엽 챌린지.** 매주 시드가 갱신되는 3분 내외의 절차적 단일 스테이지 + 글로벌 리더보드. 본편과 분리된 라이트 로그라이트 트랙으로 장기 재접속을 유도한다.

## 04 — 레벨 디자인 기본 규칙

총 6개 월드 구성, 월드마다 새로운 기믹 혹은 코그를 1개씩 도입한다. 각 월드는 아래 4단계 온보딩 패턴을 공통으로 따른다.

| 단계 | 이름 | 내용 |
|---|---|---|
| Stage 1 | 도입 | 위험 요소를 최소화한 튜토리얼 스테이지. 신규 기믹 하나만 단독으로 학습 |
| Stage 2–3 | 확장 | 신규 기믹을 기존 기믹과 결합. 난이도와 조합 경우의 수가 함께 증가 |
| Stage 4 | 반전 | 기믹을 예상 밖 방식으로 활용해야 통과되는 구간 배치, 숙련도 재확인 |
| Stage 5 | 숙달 (보스) | 해당 월드의 모든 요소를 총동원하는 보스 스테이지로 마무리 |

### 마이크로 난이도 조절

- **목숨 개념 폐지** — 사망 시 0.3초 내 체크포인트 즉시 리스폰으로 좌절감을 최소화하고 도전 자체의 진입장벽을 낮춘다.
- **체크포인트 밀도 차등** — 초반 월드는 넓고 관대하게, 후반 월드는 좁고 정밀하게 배치해 자연스러운 긴장감 곡선을 만든다.
- **난이도 이중 트랙** — 모든 스테이지에 '표준 경로'와, 더 짧지만 오버드라이브·코그 숙련을 요구하는 '기어숲 심연 경로(하드 변형)'를 병렬 배치. 초심자는 무시해도 무방하고 코어 유저에게는 별도 도전 목표가 된다.

### 재플레이(회차 플레이) 유도 요소

- **3단 수집 요소**: 히든 시드(체력 확장 재화), 골든 코그 파츠(코그 강화 재료), 스피드런 메달(구간 타임 브론즈·실버·골드).
- **듀얼비전 챌린지 룸**: 클리어 후 재방문 시에만 개방되는 보너스 구간으로, 블룸 시프트를 연속으로 오가야 통과 가능한 고난도 설계.
- **빌드별 대체 루트**: 코그 재배치에 따라 통과 가능한 경로가 달라지도록 다중 루트를 배치, 같은 스테이지도 다른 체감을 준다.
- **주간 절차적 챌린지 + 리더보드**: 3장의 '주간 태엽 챌린지'와 연동해 본편 클리어 이후의 장기 리텐션을 확보한다.

## 05 — 몬스터 및 보스전 기획

### 일반 몬스터 3종

#### 코그마이트 (Cogmite)
*정찰형 병정개미 자동인형*

- **공격 방식**: 평상시 왕복 순찰, 플레이어 감지 시 직선 돌진 태클.
- **처치법**: 스톰프(밟기) 또는 대시로 튕겨내기.
- **차별 포인트**: 처치 후 남는 등딱지 톱니가 3초간 임시 발판으로 활용 가능 — 처치가 곧 자원화로 이어진다.

#### 스포어 스프라이트 (Spore Sprite)
*공중부유 자연 정령형*

- **공격 방식**: 접근 시 포자 구름을 살포해 화면 일부를 가리고 이동속도를 소폭 저하시킨다.
- **처치법**: 일반 공격은 무효. 대시의 무적 프레임으로 몸통을 관통 타격해야만 처치된다.
- **차별 포인트**: 이동 스킬 숙련도를 직접 시험하는 배치형 몹.

#### 프레셔 피스톤 (Pressure Piston)
*고정형 기계 트랩*

- **공격 방식**: 일정 주기로 증기를 내뿜으며 왕복. 직접 공격 판정은 없는 환경 장애물형.
- **무력화**: 블룸 시프트로 자연 상태 전환 시 무해한 꽃대로 변형되어 발판화 가능.
- **차별 포인트**: 액션이 아닌 '시스템 이해'로 돌파를 유도하는 학습형 배치.

### 1스테이지 보스 — 테라코그 (TerraCog)

*뿌리와 태엽이 융합된 수호목 골렘*

큐레이터가 파견한 최초의 '조정자' 유닛. 스프라우트를 오류로 판단해 제거하려 하지만, 실은 원래 숲을 지키던 관리 기계였다는 복선을 처음으로 드러내는 존재다.

| 페이즈 | HP | 내용 |
|---|---|---|
| Phase 1 | 100–66% | **기계 상태 — 피스톤 강타.** 피스톤 팔로 지면을 내려찍어 부채꼴 충격파를 2연발로 발사한다. 팔 관절의 노출된 코어가 약점이며, 착지 직후 0.5초간 스톰프로 타격할 수 있다. |
| Phase 2 | 66–33% | **자연 강제 전이 — 덩굴 범람.** 격노한 보스가 아레나 절반을 강제로 '자연 상태'로 뒤덮어 발판이 불안정한 덩굴숲으로 변한다. 플레이어가 직접 블룸 시프트로 해당 구역을 재전환해 발판을 고정해야 접근로가 열린다. |
| Phase 3 | 33–0% | **이중 전이 — 최종 코어.** 기계·자연 상태를 스스로 빠르게 반복 전환하며 공격 패턴도 함께 바뀐다(기계=충격파 / 자연=가시 덩굴). 보스 머리 위 루트 포인트에 루트훅으로 스윙 진입 후, 급강하 스톰프로 코어를 직접 타격해야 전투가 마무리된다. |

**Phase 3 전투 연계 시퀀스** (3대 시그니처 시스템 연계 학습의 완성 단계)

1. 보스가 기계 ↔ 자연 상태를 1.5초 간격으로 빠르게 무작위 전환한다.
2. 보스 머리 위 '루트 포인트'는 **자연 상태**일 때만 덩굴이 피어나 활성화된다.
3. 플레이어는 블룸 노드를 타격해 보스의 상태를 자연으로 강제 유도한다.
4. 활성화된 루트 포인트에 루트훅으로 스윙 진입 → 공중 급강하 스톰프로 코어 타격 (총 3회 반복해야 처치).

> **설계 의도.** 이 보스전은 본작의 3대 시그니처 시스템 — 블룸 시프트 · 루트훅 · 대시 무적프레임 기반 스톰프 — 을 한 번에 모두 시험하는 '튜토리얼 보스'로 기능하며, 이후 스테이지에서 마주할 난이도의 예고편 역할을 겸한다.
