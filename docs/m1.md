# M1 코어 루프 (기획서 프롬프트 4)

무기 5종 · 패시브 5종 · 진화 · 웨이브 디렉터 · 보스 1종. 전부 데이터 주도.

## 무기 5종 + 진화 5종

동작(behavior)은 스크립트가, 정체성과 수치는 `.tres`가 갖는다.
같은 behavior면 새 무기는 `.tres` 하나로 끝난다.

| 무기 | behavior | 스크립트 | 진화 조건 | 진화형 |
|---|---|---|---|---|
| 야전삽 | MELEE_ARC | `melee_arc_weapon.gd` | Lv8 + 탄띠 | 굴삭기 (전방위 180°) |
| K-2식 소총 | PROJECTILE | `projectile_weapon.gd` | Lv8 + 계급장 | 분대지원화기 (3점사 관통) |
| 수통 | GROUND_AREA | `ground_area_weapon.gd` | Lv8 + 전투화 | 급수차 (대형 장판) |
| 예초기 | AURA | `aura_weapon.gd` | Lv8 + 전투화 | 트랙터 (범위 2배) |
| 연막탄 | THROWN | `thrown_weapon.gd` | Lv8 + 시계 | 다연장 발연통 (5발 동시) |

> 기획서 5.1은 수통 진화 조건을 "+군화"라고 적었는데 5.2의 패시브 10종 목록에 군화가
> 없다. 전투화의 다른 표기로 보고 전투화로 통일했다. 결과적으로 수통과 예초기가 같은
> 패시브를 요구하는데, 한 패시브가 두 진화를 여는 건 이 장르에서 흔한 구성이라 그대로 뒀다.

`WeaponData` 는 칸이 넉넉하지 않아 behavior별로 몇 칸을 재활용한다.
- `GROUND_AREA` / `THROWN`: `half_angle_deg` = 장판 지속시간(초)
- `PROJECTILE`: `knockback` = 관통 횟수

## 패시브 5종

전투화(이속) · 탄띠(투사체 +1) · 계급장(공격력) · 시계(쿨감) · 건빵(최대체력 + 초당 회복).

무기는 `WEAPON_GRANT` 명령서 하나로 지급과 레벨업을 겸한다. 처음 뽑으면 지급, 이후로는
레벨업. 뽑은 **횟수**가 아니라 **실제 무기 레벨**을 기록하기 때문에 Lv8에서 정확히 후보에서 빠진다.

## 진화

보스를 잡으면 보물상자를 떨군다. 밟으면 조건을 만족한 무기 하나가 진화한다.
진화할 게 없으면 빈손으로 보내지 않고 체력 35% + 경험치로 바꿔준다.

## 보스 — 대대장 순시 (5분)

`APPROACH → (TELEGRAPH → CHARGE → RECOVER) 또는 SUMMON` 을 번갈아 돈다.
돌진 전에 진홍색 선으로 예고하고(기획서 3.2 — 진홍 = 무조건 피해야 함), 소환 때는 링을 그린다.

**보스 몸통도 `EnemyManager` 배열 안에 있다.** 개별 Node로 빼면 모든 무기·장판·투사체가
"적 배열 + 보스"를 따로 때려야 해서 배선이 두 배가 된다. 대신 `spawn_tracked()` 로 받은
**핸들**로 지목한다 — 배열 인덱스는 swap-remove 때문에 프레임 사이에 유지되지 않기 때문이다.
`EnemyData.speed = 0` 이라 `EnemyManager` 는 보스를 밀지도 끌지도 않고, 위치는 컨트롤러가 잡는다.

## 새로 생긴 매니저

둘 다 적과 같은 SoA + MultiMesh 방식이다. 개별 Node를 만들지 않는다.

- `ProjectileManager` — 직선 총알(STRAIGHT)과 투척물(LOB)을 한 배열에서 굴린다.
  투척물은 착탄하면 즉발 피해 + 장판을 남긴다.
- `AreaManager` — 장판. **초당 4번만** 판정한다(60Hz로 훑을 이유가 없다).

## 확인된 것

```
tools/playthrough.sh --runs=2 --scale=8      # 20분 한 판을 끝까지 자동 플레이
  1 | 1200.0s | 16064처치 | Lv.50 | 무기 3종 | 전역
  2 | 1200.0s |   330처치 | Lv. 7 | 무기 2종 | 전역
```

**배속을 8보다 올리지 말 것.** `time_scale 20`이면 물리 1틱 델타가 0.33초라 플레이어가
한 틱에 67px씩 순간이동한다. 획득 반경 18px짜리 '짬'을 그냥 통과해서, 5,600마리를 잡고도
Lv.6에서 끝나는 가짜 결과가 나온다. 이 함정에 한 번 빠졌다.

성능 회귀 없음: 3,000마리 물리 1틱 6.87ms (예산의 41%).

## 알려진 불균형 (M3/M5에서 조정)

- 명령서를 무작위로 고르면 결과 편차가 크다(16,064처치 vs 330처치). 가중치 조정 필요.
- 20분 완주가 아직 쉬운 편이다. 후반 밀도(`data/waves/`)를 더 올려야 한다.
- '짬'이 자석 범위 밖에서 천천히 따라오게 해뒀다. 벽 없는 맵에서 플레이어가 되돌아오지
  않기 때문인데, 맵에 경계가 생기면 다시 판단할 것.
